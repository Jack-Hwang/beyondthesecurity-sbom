# ADR-0009: 원본 증거를 캐시하고 읽을 때 해석한다

## Status
Accepted — 사후 기록. 근거 코드: `bts_sbom_app/licenses.py`(캐시된 원본 문서 저장·재해석), AC: BSA-AC-50(캐시 정책). README 의 루프 표 "패스 3 의 무변화가 측정 오류".

## 근거 (Context)
외부 정보원(deps.dev, PyPI, npm, Maven)의 응답을 정규화된 결과로 캐시하면, 나중에 정규화 규칙이 개선돼도 캐시가 옛 오류를 그대로 재생한다. README 가 기록한 실측: 정규화 결과 캐시가 "개선이 가려진다".

## 결정 (Decision)
정보원 응답의 **원본**(raw JSON/텍스트)을 캐시하고, 읽을 때마다 현재 규칙으로 다시 해석한다. 캐시 히트여도 규칙 개선의 이득이 적용된다.

## 기각 대안 (Rejected alternatives)
- 정규화 결과를 캐시: 빠르지만 규칙 개선이 캐시에 갇힌다(측정된 실제 문제).
- 캐시 없음: 같은 스캔에서 정보원에 같은 질문을 반복해 429를 유발한다.

## 결과 (Consequences)
캐시가 커지지만 저장소 비용은 작다. 해석 규칙 변경 후 재검증이 캐시로도 즉시 가능하다.
