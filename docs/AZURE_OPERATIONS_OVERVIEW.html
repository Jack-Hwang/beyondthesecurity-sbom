    Identity — Managed Identity 적용 · Workload Identity 방향
    docs/AZURE_IDENTITY.md · 2026-11-28 적용 실측
    적용 완료 — ACR 풀 = 시스템 할당 MI (리비전 0000008부터 라이브) MI principal a597a9ae-… → AcrPull → 레지스트리 항목 identity: system → acr-password 시크릿 삭제 + ACR 관리자 계정 OFF. 앱 설정·시크릿·빌드 문서 어디에도 ACR 비밀번호가 남지 않는다.
    방향 — Workload Identity(연합 자격증명)는 Key Vault 연계 시점에 대상: LLM 키 4종·액세스 토큰의 KV 이관. 사용자 할당 MI + 연합 자격증명(issuer *.azurecontainerapps.io) + KV RBAC Secrets User.
    지금 안 하는 이유: stdlib 전용 런타임에 Azure SDK가 없고 ACA 참조 방식은 앱 단위 활성화 확인이 필요 — 다음 배포 창에 적용. 대안: ACA secret은 플랫폼 암호화·마스킹 검증됨 — 실익은 사람이 KV에서 로테이션할 때.
    런타임 최소 권한: 앱이 가진 Azure 권한은 ACR pull 하나. 배포·롤백·리비전 작업은 사람의 az 세션이 수행.
