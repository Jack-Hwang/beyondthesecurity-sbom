# ISO/IEC 14882:2020 (C++20) — 정제 노트 (범위 지도)

출처: 로컬 도서 "C++20, ISO/IEC 14882:2020" (PDF, slug `c-20-isoiec-148822020-isoiec`). C++ 표준 제6판(2020-12).
이 노트는 추출 원문의 구조를 읽고 정리한 범위 지도다 — 조문 번역이 아니다. 조문별 원문은 `book_search`로 검색.

## 표준의 구조 (범위 지도)

- C++17판과 동일한 조문 골격(Scope→규범 참조→용어→일반 원칙→어휘 규약→언어 핵심→표준 라이브러리) 위에
  C++20 신규 기능이 언어·라이브러리 조부에 흡수돼 있다.
- **C++20 신규 중심**: 개념(concepts, 템플릿 요구를 언어로), 코루틴, 모듈(전처리기 대체 경로), 범위(range) 라이브러리,
  three-way 비교(<=>), 달력·시간대 라이브러리, format 라이브러리, consteval/constinit, 지정 초기화 등.
- **개념(concepts)의 의미**: 템플릿 인자 요구를 이름 붙은 술어로 — "이 인자는 무엇을 약속하는가"를 컴파일러가
  검사하는 계약 언어.

## 이 프로젝트 적용

- **계약 언어로서의 concepts**: 도구 카탈로그·정규식 라우트가 "이 도구는 무엇을 받는가"를 이름 붙은 계약으로
  선언하는 것과 같은 방향 — 인터페이스 요구를 암묵 문서가 아닌 검증 가능한 선언으로.
- **모듈과 경계**: C++20 모듈이 헤더 포함 계층을 대체하려는 움직임은 "명시적 의존 선언" 원칙 — 이 저장소의 import
  그래프 분석(arch.py)이 같은 원칙을 측정으로 다룬다.
- **판 비교 검색**: 2017/2020/2024 원문이 함께 색인돼 있으므로, "range가 언제 표준이 됐는가" 같은 판 간 비교 질의를
  `book_search`로 바로 검증할 수 있다 — 레거시 코드 감사(C++ 표준 판 지정 검토) 시의 1차 참조.
- **라이브러리 계약 읽기**: 표준 라이브러리 조부의 "복잡도·예외 보증" 명시 방식이 capacity.md·게이트 문서의
  "복잡도+한계 명시" 관행의 모범 — 새 API 문서에 복잡도와 실패 보증을 함께 적는다.
