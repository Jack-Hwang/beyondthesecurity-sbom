# ISO/IEC 9899:2024 (C23 정식 출판판) — 정제 노트 (범위 지도)

출처: 로컬 도서 "ISO/IEC 9899:2024 — Programming languages — C" (PDF, slug `isoiec-98992024-jtc-1sc-22wg-14`).
C 표준 제5판(2024-10 출판, 통칭 C23 내용의 정식판). 이 노트는 추출 원문 구조의 범위 지도다 — 조문 번역이
아니다. 원문은 `book_search`로 검색.

## 표준의 구조 (범위 지도)

- C17과 같은 조문 골격(Scope→규범 참조→용어→규합→환경→언어→라이브러리) 위에 최신 기능이 흡수:
  - **언어**: 진위형(bool)·true/false 키워드, auto 형 추론, constexpr 개선, 라벨 뒤 선언, 이진 리터럴, 디지트
    구분자, #embed(자원 임베딩), 개선된 열거형 등.
  - **라이브러리**: memset_explicit 같은 보안 관련 함수, 표준 스마트 포인터 계열의 검토된 접근, 체크된 산술·
    범위 계열(AP 뒤 본편 흡수) 등의 확장.
  - **정적 보증**:Annals K 계열(안전 규합 프로파일)의 방향성이 언어·라이브러리 계약에 반영.

## 이 프로젝트 적용

- **보안 함수 계약**: 보안성 문서(VEX·권고)에서 C 계열 레거시의 위험 함수 사용 검토 시 "최신 표준의 대체
  함수·한계"를 조 번호로 `book_search` 검색 — 권고문의 근거 인용.
- **한계 문서 관행**: 2018판 노트와 동일 — 모든 환경 한계는 문서+테스트. 새 상한·한계 도입 시 C 표준의
  "환경 고려" 조 형식을 따른다.
- **판 간 이식성 감사**: 2018/2024 두 판 원문 대비로 "이 코드가 C17 가정인지 C23 기능을 쓰는지" 판별 가능 —
  레거시의 표준 판 지정(컴파일러 플래그·#if __STDC_VERSION__) 감사의 근거.
- **정적 보증 방향성**: 표준이 안전 프로파일 방향으로 가는 흐름은 이 저장소의 "정적 검사(린트)로 계약을 강제"
  관행과 같은 방향 — 언어 수준 계약도 기계 검사로 옮기는 흐름을 표준 문서가 보증한다.
