# BS ISO/IEC 14882:2024 (C++ 최신판, BSI 출판) — 정제 노트 (범위 지도)

출처: 로컬 도서 "BS ISO/IEC 14882:2024 — Programming languages — C++" (PDF, slug
`bs-isoiec-148822024-programming-languages-c-the-british-standards-institution`). ISO/IEC 14882:2024의 영국 표준
(BSI) 출판판 — UK 국가 전언(national foreword, 기술위원회 IST/5)이 앞에 붙어 ISO 본문은 그대로다. 커뮤니티에서
"C++23"으로 부르는 내용의 정식 국제 표준 출판판이다. 이 노트는 추출 원문 구조의 범위 지도다 — 조문 번역이
아니다. 원문은 `book_search`로 검색.

## 표준의 구조 (범위 지도)

- **국가 전언**: BSI가 ISO 판을 영국 표준으로 채택하며 성실 선언·책임 부인·위원회 정보를 붙인다 — 국제 표준의
  "조달 언어" 계층(ISO 본문과 별개의 법적 포장).
- **본문**: 전언→서론→Scope→규범 참조→용어→일반 원칙→어휘 규약→언어 핵심→표준 라이브러리의 C++ 표준 표준
  골격 유지. C++20판 대비 최신 언어·라이브러리 기능(예: 표준 모듈 std, 라이브러리 신규 구성요소 등)이 조부에
  반영돼 있다.

## 이 프로젝트 적용

- **표준의 채택 계층**: ISO 본문 vs 국가 채택(BS)의 이중 계층은 conformance.py의 "regime(규제 체계)별 요구" 설계와
  동형 — 같은 기술 내용도 채택 체계에 따라 계약 문구·범위가 달라진다. 새 regime 추가 시 "본문 vs 채택 포장"
  을 구분해 문서화.
- **책임 부인의 정직성**: BSI 전언의 명시적 책임 부인이 RUNBOOK의 정직 문단("측정하지 않은 것은 측정하지 않았다")
  와 같은 문법 — 보증을 못 하는 것은 못 하는 대로 정확히 쓴다.
- **세 판 원문 비교**: 2017→2020→2024 원문이 모두 색인돼 있어 C++ 레거시 코드의 표준 판 지정 검토·기능 도입
  시점 질의를 `book_search`로 해결 — 국가 출판판까지 포함해 조달 문서(구매 명세가 BS 번호를 쓰는 경우) 검토
  시에도 대응.
