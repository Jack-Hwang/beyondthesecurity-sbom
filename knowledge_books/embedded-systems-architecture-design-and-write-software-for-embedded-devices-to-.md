# Embedded Systems Architecture (Daniele Lacamera) — 정제 노트

출처: 로컬 도서 "Embedded Systems Architecture — Design and write software for embedded devices to build safe and
connected systems" (PDF, slug
`embedded-systems-architecture-design-and-write-software-for-embedded-devices-to-`). 추출 원문을 읽고 우리 말로
정리한 종합 — 원문 인용이 아니다. 원문 검색은 `/api/books/search` 또는 `book_search`.

## 이 책의 논지

자원 한정 마이크로컨트롤러 위에서 안전·연결된 시스템을 만드는 임베디드 아키텍처 입문. 주변장치는 클록 게이팅으로
활성화하고 메모리 공간에 매핑된 설정 레지스터로 제어하며, 직렬 버스 핀은 대체 기능(alternate function)으로
구성하고 인터럽트 라인은 벡터 테이블에 연결한다. **DMA(Direct Memory Access)** 는 주변장치와 RAM 사이 전송을
CPU 대신 수행해 통신 데이터 처리 시간을 줄이고 응답성을 높인다 — DMA 컨트롤러를 전송 개시로 프로그래밍하고
완료 시 인터럽트를 트리거하게 한다.

## 핵심 개념 지도

- **메모리 매핑 제어**: 레지스터=메모리 주소 — 하드웨어 제어도 계약(레지스터 맵)으로.
- **인터럽트·DMA 모델**: CPU를 막지 않는 비동기 완료 통지(완료 인터럽트) — "기다림"을 "통지"로 치환.
- **클록 게이팅·전력**: 안 쓰는 회로는 끈다 — 자원은 기본적으로 희소.
- **안전·연결**: 워치독·펌웨어 갱신·통신 스택의 방어 설계.

## 이 프로젝트 적용

- **"기다림을 통지로"**: 서버의 배경 작업(스캔·books ingest)이 스레드+이벤트 버스로 완료를 통지하는 설계가 이
  모델과 동형 — 동기 대기(요청 블로킹)를 피하고, 완료 이벤트로 상태를 알린다. 새 무거운 작업은 같은 패턴
  (작업 큐+EventBus+/api/jobs 폴링)으로.
- **기본 희소·게이팅**: 큰 인덱스(책 22,857 청크)를 항상 메모리에 두지 않고 레지스트리 시그니처로 게이팅해
  필요할 때 구성하는 2차 인덱스 캐시 — "안 쓰면 끈다" 원칙의 소프트웨어판.
- **계약된 하드웨어/인터페이스 맵**: 레지스터 맵처럼, 이 앱의 HTTP API·이벤트 유형도 고정 맵(주석·문서화된
  경로)으로 취급 — 임의 확장 없이 맵에 항목을 추가하는 방식.
- **방어적 초기화**: 임베디드의 방어 설계(워치독)에 대응하는 것이 이 앱의 서킷브레이커·타임아웃·readyz — 외부
  세계는 반드시 실패한다는 전제.
