# MODULE_OWNERS.md

BTS-SBOM is built by several agents/sub-agents working in parallel, each in
its own worktree or branch. Without a shared boundary table, two agents can
edit the same top-level directory at the same time and overwrite each
other's work — the same "concurrent agent committing" conflict pattern
recorded for ECU_Sentinel's end-to-end harness.

This table assigns exactly one owning scope to each top-level directory in
this repository. A scope is a role, not necessarily a single person: more
than one agent may act under the same scope, but every top-level path maps
to exactly one scope, and no scope's path nests inside another's. Before
starting work on a path, confirm here which scope owns it; if your task
needs to touch a path you do not own, say so instead of editing it (see
CONTRIBUTING.md for the PR process, and docs/WORKFLOW.md for how release
work is sequenced across scopes).

`tests/test_method_module_owners_map.py` checks this table mechanically: it
fails if any top-level directory is missing a row, owned by more than one
row, or if two rows claim overlapping/nesting paths.

| Path | Owner / scope | Notes |
|------|----------------|-------|
| `bts_sbom/` | core-scanner-scope | Stdlib-only scan/SBOM/vulnerability engine; CLI `bts-sbom`. |
| `bts_sbom_app/` | app-layer-scope | Web UI, chat/RAG, patch/policy app layer; CLI `bts-sbom-app`. |
| `docs/` | release-docs-scope | Architecture, workflow and lecture-mapping docs; regenerated by the release session. |
| `evals/` | app-layer-scope | RAG/chat evaluation fixtures consumed by `bts_sbom_app/evals.py`. |
| `evidence/` | app-layer-scope | Runtime evidence sidecar: loop history and batch-run summaries. |
| `examples/` | core-scanner-scope | Sample SBOM/VEX/EOL fixtures used by core examples and docs. |
| `knowledge/` | app-layer-scope | RAG knowledge corpus indexed by `bts_sbom_app/rag.py`. |
| `specs/` | release-docs-scope | EARS acceptance-criteria spec; ACs are appended by the release session. |
| `tests/` | shared-test-scope | Test suite for both layers; `tests/bts_sbom_app/` is app-only within it. |
| `tutorials/` | release-docs-scope | End-user walkthroughs. |

Directories outside this table (`.git/`, `.github/`, caches) are VCS/CI
metadata, not product modules, and are not owned by a product scope.
